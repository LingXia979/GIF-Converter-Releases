# GIF Converter

<img src="app-icon.png" width="112" alt="GIF Converter 粉紫色举牌图标">

在 Android 手机上制作和处理 GIF 的本地工具。图片、视频和动图在手机上处理，无需上传到转换服务器；结果可以预览、保存到相册和分享。

**v0.1.3 公开测试版：文字批注、结果快捷处理与中英文界面。** 支持 Android 10 及以上的 arm64 手机。本仓库提供 Android 安装包、界面介绍、使用说明及第三方组件材料；应用源码仓库继续私有。

## v0.1.3 新增了什么

- **结果快捷处理：** 图片或视频转 GIF 完成后，点击“编辑 / 压缩 / 拼接”直接带入当前结果。历史中的 GIF 也可继续处理，原结果保留。
- **文字批注：** “GIF 编辑 → 文字批注”可添加多段文字，拖动位置、调整字号和颜色，设置粗体、描边与半透明底色；支持撤销/恢复。
- **指定显示帧：** 默认整段显示，也可指定原始起止帧，范围包含首尾；删帧、倒放时文字跟随对应画面。最多 8 段，每段 120 字符。
- **中英文切换：** 首页设置 →“语言 / Language”，可选跟随系统、中文或 English，立即切换并在重开后保留；系统语言不匹配时回退英语。
- **生成修复：** 修正较长文字图层在 Android 上可能无法生成的问题。

原有拼接旋转、自动转向、越界裁切与历史筛选继续保留。完整使用方式与验证范围见[本版发布说明](RELEASE_NOTES.md)。

## 支持的功能

保留历史按功能/日期筛选、可拖动的日期范围，以及固定位置的居中选项按钮。沿用粉紫色举牌图标，适配 Android 圆形、圆角和系统主题图标。

- **图片转 GIF**：调整顺序、帧间隔、输出尺寸，以及横向、竖向或方形画布和补边。
- **视频转 GIF**：选择片段和画面区域，调整输出尺寸、帧率与播放速度。
- **GIF 编辑**：裁切片段、删帧、裁剪、旋转、缩放、变速、倒放、播放次数与撤销/恢复；支持多段文字及指定显示帧范围。
- **GIF 压缩**：三档预设；没有进一步缩小时保留原 GIF。
- **GIF / 视频分解**：预览和选帧，直接保存 PNG 到相册，或导出 ZIP。
- **GIF 拼接**：顺序、左右、上下和自定义画布；支持逐张转向、自由拖动/旋转/等比缩放、自动转向排列、出界裁切、透明/浅灰背景及可选网格吸附。
- **生成历史**：查看 App 内的 GIF 和分解结果，再次预览或保存，GIF 还可分享；支持单条或批量删除。
- **历史筛选**：七种功能可多选，可指定某天或包含首尾的日期范围；预览返回和刷新保留条件。日期范围首尾可拖动，靠近上下边缘可跨月滚动，也能点选或输入日期。全选只作用于当前筛选结果，换条件会清除旧勾选。

## 手机性能与兼容性

本地转换会占用处理器、内存和存储，可能增加耗电、使手机发热。建议先用少量图片、短片段和较低尺寸或帧率尝试；尽量避免边充电边连续处理大任务。明显发烫或系统提示温度过高时，请取消任务，等待降温。当前版本没有自动温度监测或过热暂停功能。

此前兼容测试在 Android 10（型号未提供）和 Android 16（维护者设备 BKQ AN80）已收到正常使用反馈。本版正式签名 APK 在 Android 16 验证覆盖更新、文字生成和相册保存，用户确认快捷入口、文字操作及指定帧结果正常；语言切换、重开保留与英文日期已检查。本次新增功能未在 Android 10～15 逐项复测。其他机型及真正的 16 KB 页面环境仍待补充验证。相册可能忽略 GIF 循环次数，对透明背景或缩放的显示也可能不同。

视频源片段目前支持 0.1～10 秒；拼接支持 2～6 个 GIF、输入合计最多 600 帧、输出最长 120 秒。请保留原素材并检查生成结果。
